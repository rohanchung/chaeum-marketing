# 로한 마케팅 — 최신 인계 안내

최종 갱신: 2026-09-16. 현재 이력은 **제1차 제작방 및 후속 수정**까지 정리했다.

**최신 후속 결정:** [지표 집계 방식 수정](update-20260916-metric-aggregation.md)을 함께 읽는다. 당근 단골수는 사용자가 일별 신규 수를 입력하므로 합산(daily)으로 변경했다. 기록이 있는 지표도 raw 집계 방식(daily/cumulative/latest)을 수정할 수 있다. 이전 인계의 ‘단골수 마지막 관측’과 집계 변경 금지 설명보다 이 결정이 우선한다.

## 다음 방에서 먼저 읽을 문서

1. [제1차 제작방 핸드오프](HANDOFF-PHASE1.md): 제품 합의, 현재 구현, 계산 원칙, 개발·배포·검증 방식.
2. 루트 `AGENTS.md`: 매 업데이트의 로그·문서·커밋 전달 규칙.
3. 사용자의 새 요청에 해당하는 `docs/update-*.md`와 실제 코드. 인계 이후 사용자가 입력한 데이터는 보존한다.

## 이어서 남기는 방법

- 기능 업데이트마다 앱 로그(`web/src/lib/update-history.ts`)와 상세 변경 문서를 함께 갱신한다.
- 새 제작방을 마칠 때 해당 방의 핸드오프를 추가하고 이 문서의 최신 링크를 바꾼다. 제작방 이름이 지정되지 않았다면 임의로 번호를 확정하지 않는다.
- 기존 핸드오프는 과거 기록으로 남긴다. `HANDOFF-ASTRA.md`는 초기 설계·미완료 상태에 관한 역사 자료로, 현재 개발 지시가 아니다.
