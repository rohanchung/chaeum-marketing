# 로한 마케팅 — 제1차 제작방 핸드오프

작성: 2026-09-15. 로한은 이후 다른 제작방에서 기획·수정하고 그곳에서도 핸드오프를 남길 예정이다. 이 문서는 제1차 제작방 종료 시점의 합의와 구현 상태다. 새 요청이 이 문서보다 우선한다.

## 제품 목적과 합의

채움영어학원 풍무캠퍼스의 마케팅을 로한이 직접 입력·관리하는 운영 도구다. 현재 상용 다중 학원 SaaS를 확장하는 단계가 아니다. 각 채널의 서로 다른 성과 지표를 학원 유입→상담→등록, 마케팅 비용, 수납·환불과 함께 보되 확인되지 않은 인과관계를 만들지 않는다.

핵심 화면은 가로 날짜 운영시트다. 학원 전체 퍼널을 맨 위에, 실제 채널과 하위 운영대상·지표를 가운데, 학원 전체 비용 효율을 아래에 둔다. 별도의 유료/콘텐츠 대분류를 강제하지 않는다. 이벤트·구매 등 자세한 기록은 별도 메뉴로 관리하고 결과를 시트에 연결한다.

메뉴: 대시보드 / 콘텐츠 / 이벤트 / 구매 / 분석 / 리포트 / 로그. 뒤로·앞으로 이동은 URL 해시와 연동된다. 앱 이름은 **로한 마케팅**, M 모양 아이콘. 채움영어는 실제 학원 이름이므로 임의 변경하지 않는다.

## 로한과 일하는 방식

- 개발 전권을 부여했지만 새 변경 범위는 각 요청에 맞춘다. 이미 승인된 일에 반복 확인을 요구하지 않는다.
- 로한은 비개발자이자 기획자. 토큰·비용을 아끼고 빠른 구현→피드백→수정을 선호한다. 작은 변경에 장황한 조사·설명·대규모 리팩터링을 하지 않는다.
- 내부 JS 테스트, DB 저장·재조회 검증, 적절한 빌드가 기본이다. 오른쪽 미리보기 창과 큰 화면 트리 반복 조회를 피한다. 시각 검증이 꼭 필요할 때만 최소 사용한다.
- 기존 실제 입력 데이터는 반드시 보존한다. 기능을 일부만 만들고 완료했다고 선언하지 않는다. 가짜 버튼·저장되는 척하는 UI를 만들지 않는다.
- **에이전트가 커밋·푸시하지 않는다. 매 업데이트 완료 후 Summary / Description을 복사 가능한 블록으로 제공**하고 로한이 GitHub Desktop에서 수행한다.
- 기능이 바뀔 때 앱의 로그 페이지와 상세 변경 문서도 갱신한다. 제작방을 마치면 새 핸드오프를 작성하고 최신 링크를 갱신한다.

## 반드시 유지할 계산 원칙

1. 미입력(null)과 실제 0은 다르다. 누적/최근 관측은 마지막 값이며 합계나 최대값으로 계산하지 않는다. CTR 같은 비율은 원시 합계에서 재계산한다.
2. 학원 전체 지표의 funnel_role로 유입·상담·등록을 묶는다. 일일 학원 집계와 개별 고객 기록은 서로 더하지 않는다. 출처 미확인/운영자 추정 매출을 임의로 채널에 배분하지 않는다.
3. 전체 지출은 지급 완료 원장 + 합산을 선택한 일별 금액 지표 + 구매 결제액이다. 금액 지표는 include_in_marketing=true만 포함. 원본 값과 비용 원장 표시를 이중 저장/합산하지 않는다.
4. 구매비는 구매·결제일에 한 번 지출로 반영. 이벤트 물품 원가는 사용량×해당 구매 건 단가이며 전체 현금 지출에 다시 더하지 않는다. 이벤트 전체 원가=물품 원가+연결된 직접 지급 비용. 분석의 기간별 이벤트 물품 원가는 이벤트 시작일 기준이다.
5. 예: 볼펜 500개 100,000원 구매, 이벤트 사용 150개, 장소비 50,000원 → 잔량350, 이벤트 원가80,000원, 총 현금 지출150,000원. 서로 다른 구매 단가를 하나로 뭉개지 않는다.
6. 수량 초과와 사용 내역이 있는 구매 삭제는 서버에서 차단. 반납은 사용량 감소/제거. 이벤트 취소·휴지통만으로 이미 사용한 수량을 되돌리지 않는다.
7. 순위는 rank 단위+latest 방식 고정. 1이 최상위. 미노출은 내부 저장값0, UI·보고서에는 ‘미노출’. 사용자 숫자0 입력은 거절하고 ‘미노출’을 입력하도록 안내. 미입력은 빈칸. 키워드끼리 순위를 합산하지 않는다.
8. 순위 월간 요약=선택 기간 최근 순위/직전 관측 대비 변화/기간 최고 순위(양수 최솟값). 직전 관측은 전달까지 참조할 수 있다. 미노출 전환·재노출을 별도로 표시.
9. 전체 ROI=(순수납-서비스 원가-마케팅 비용)/마케팅 비용. 서비스 원가가 누락되면 미산출. 객단가=순수납/기간 내 양수 결제한 고유 고객 수. 연간 객단가를 월별 평균으로 만들지 않는다.
10. 삭제·아카이브가 실제 비용·수납 원장을 임의로 없애지 않게 한다. 채널·소재·집행은 중첩된 조회 수준이므로 각 행을 다시 합산하지 않는다.
