## 1단계 — 업무 캘린더 표시 방식 재설계

반복된 "5주차 잘림" 수정의 원인은 주 높이를 일정 수에 맞추는 구조와, 같은 셀렉터를 8회 덮어쓴 CSS다.

- **하루 최대 3줄 + `+N개`**: 한 주에 표시하는 바를 3줄로 제한하고 넘치는 날짜는 `+N개`를 표시. 누르면 그 날짜가 선택돼 오른쪽 목록에 전부 나옴. 주 행은 항상 같은 높이.
- **월 전환은 `Shift + 휠`로만** — 캘린더 내부 스크롤과 충돌 방지.
- **CSS 정리**: 업무 화면의 `.calendar-*`, `.task-*` 규칙을 한 블록으로 모으고 중복 덮어쓰기 제거.
- **가독성**: 캘린더 바·카드 보조 텍스트 최소 11px. 헤더의 초 단위 시계 제거(분 단위 또는 삭제).
- **순수 함수 분리**: 주별 바 배치·레인 계산을 `lib/task-calendar.ts`로 빼고 단위 테스트 추가.

검증: 1280×800, 1366×640, 1920×1080에서 9월(5주)·6주 달 화면 확인, 레인 계산 테스트.

## 2단계 — 오른쪽 패널 "오늘 보드" (요구사항 5.1, FR-015)

- 기본 모드는 **오늘 보드**: `기한 초과` / `오늘` / `날짜 미정` / `반복 업무` 섹션. 기존 `TodayActivity` 컴포넌트를 재활용.
- 캘린더 날짜를 누르면 **선택일 모드**로 전환, 상단에 `← 오늘 보드` 버튼.
- 날짜 미정 업무를 다시 허용: 새 업무의 날짜 기본값은 오늘로 두되, 비우면 `날짜 미정`에 표시.
- 필터 정리: "오늘" 필터는 오늘 보드로 대체하고 제거. 남는 필터(요청받은 업무 / 반복 업무)는 **교집합(AND)** 으로 동작하도록 변경. 월 이동 버튼의 `오늘`과 이름 충돌 해소.

검증: 기한 초과·날짜 미정·반복 업무가 각각 올바른 섹션에 1회만 표시되는지 단위 테스트.

## 3단계 — 업무 카드와 조작

- **정렬**: 완료·취소 업무는 목록 아래로 내림(수동 순서는 미완료끼리 유지).
- **정보 압축**: `내가 만든 업무`는 표시하지 않고 요청·반복일 때만 배지. 등록·실행·마감이 같으면 날짜 1개만 표시.
- **드래그 안전성**: 카드 위·아래 놓기는 순서 변경만. 하위 업무 지정은 오른쪽으로 끌어 들여쓰기 또는 `⋯ > 하위 업무로`.
- **완료 시 처리 결과(FR-016)**: 체크하면 즉시 완료하고, 카드에 한 줄 `처리 결과 남기기` 입력을 잠시 노출(강제하지 않음).

## 4단계 — 대시보드 개편안 1단계 잔여분

- 지표 행의 `↑ ↓ ×`, 채널·소재 행의 버튼을 행 호버 시에만 보이는 `⋯` 메뉴로 통합.
- 시트 상단 `삭제한 지표`를 `⋯ 더보기`로 이동.
- 월간 요약 열의 대표 지표 선택: 값은 한 줄 오른쪽 정렬, 지표 선택은 작은 라벨 + 드롭다운으로 분리해 줄바꿈 제거.

검증: 입력·붙여넣기·되돌리기·집계 결과가 변경 전과 동일한지 기존 테스트 + 수동 확인.
