# 마케팅 운영과 수익성 — 구현 기준

2026-09-11. HANDOFF-ASTRA와 이후 로한의 지시가 종전 UI 설계보다 우선한다.

- 채널 > 소재 > 전체/자연 유입 지표, 소재 > 여러 광고 집행 > 광고 지표. 고정 유료/콘텐츠 상위 그룹은 없다.
- 학원 일일 퍼널은 전체 집계다. 개별 고객 기록은 출처와 상담→등록을 확인한 기록이며 전체 집계에 더하지 않는다.
- 상담 경로별 건수의 합은 사람 수가 아니다. 실제 전환율은 최초 상담일 기준 고객 집단 중 조회 종료일까지 등록한 사람 수로 계산한다.
- 원본 지표의 측정 대상, 단위, 범위, 일별/누적/최신 방식은 저장한다. 값이 존재하면 측정 의미를 변경할 수 없고 새 지표를 만든다.
- 누적값은 조회 기간 안의 마지막 관측을 표시하며 관측일을 함께 제공한다. 현재 버전은 월간 증가분을 자동 계산하지 않는다. 도달 등 중복 제거 지표의 누적 차이를 월간 도달로 표현하지 않는다.
- 비율은 같은 범위 원시 집계로 재계산한다. 지표값에 광고비를 중복 저장하지 않는다. 광고비는 비용 원장의 일별 집행 비용이다.
- 비용은 실제 지급(paid) 기준이며 계획/미지급/취소는 제외한다. 제작비·굿즈·행사·대행·공용 비용을 포함한다.
- 매출은 실제 결제일 기준 등록 관련 수납액이다. 환불은 음수 조정 거래와 원거래 연결로 보존한다. 예상매출은 포함하지 않는다.
- 객단가 = 기간 순수납액 / 해당 기간 양수 결제한 고유 고객 수. 환불만 있는 기간은 계산하지 않는다.
- 기간 마케팅 ROI = (기간 순수납액 - 입력된 서비스 원가 - 마케팅 비용) / 마케팅 비용. 원가 누락 시 계산하지 않는다. 전체 사업의 순이익이나 마케팅의 인과적 기여를 뜻하지 않는다.
- 광고 ROAS = 광고 집행을 주 출처로 확인한 고객의 기간 수납액 / 광고 집행 지출. 전체 마케팅 비용을 분모로 하는 값은 매출/마케팅비로 명명한다.
- 고객의 주 출처는 채널/소재/광고 집행/이벤트 중 하나. 고객 응답·직접 확인만 귀속하며 추정·미확인은 전체 성과에만 포함한다. 보조 접점으로 매출을 중복 배분하지 않는다.
- 아카이브는 운영 중 표에서 숨겨도 기간 이력과 보고에 포함한다. 휴지통 소재/채널의 성과는 기본 보고에서 제외하며 연결 비용·수납 원장은 보존하고 제외하지 않는다. 귀속 표에는 휴지통 표시로 남긴다.
- 데이터 보존: soft delete, 감사 로그, 보고서 스냅샷, 전체 JSON 내보내기/동일 작업공간 복원을 제공한다. 영구 무손실을 보장하는 자동 외부 백업은 별도 운영 검증 사항이다.
- JSON 복원은 현재 앱에서 사용하는 테이블의 동일 ID 기록을 덮어쓰며 백업에 없는 새 기록은 삭제하지 않는다. 함께 내보낸 종전 스키마 기록과 감사 로그는 열람·보존용이며 복원 RPC의 수정 대상이 아니다.
- 완료 검증: 독립 지표 저장, 다중 셀 입력, 집행 기간 검증, 기간 집계, 누락/0 구분, 환불·객단가·ROI, 로그인 역할 RLS, 보고서 동일 계산.
