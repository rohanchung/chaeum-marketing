# 당근 마켓 비즈프로필 분리

- 기존 당근 광고 채널명을 당근 마켓으로 변경했다.
- 광고 소재 위에 비즈프로필을 생성했다. 방문수·쿠폰 발급수는 일별 합계, 단골수는 날짜별 총 단골 수를 기록하며 기간 마지막 값을 표시한다.
- 시트와 보고서 모두 프로필 지표를 광고 소재와 분리한다. 프로필에는 광고 집행·지출 입력 행을 만들지 않는다.
- 값이 없던 광고 도달·단골·관심·쿠폰 다운로드 항목만 소프트 삭제했다. 노출·클릭·반응·지출과 자동 계산은 유지한다.
- 운영 데이터 변경 SQL은 `supabase/operations/20260914_carrot_business_profile.sql`에 보관했다. 적용 시 기존 지표 값 및 비용 전체 해시가 변경되지 않았음을 확인했다. 스키마 변경은 없다.
- 내부 회귀 테스트 21개와 타입·린트 검사, 배포 빌드 통과. 로그인 권한으로 비즈프로필 지표 3종 저장·재조회를 확인하고 전체 롤백했다. 테스트 값은 남기지 않았다. 브라우저 검증은 생략했다.
