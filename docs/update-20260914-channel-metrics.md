# 소재 없는 채널 지표

- 비틀리의 페이지뷰·클릭은 생성돼 있었으나 소재가 없어서 표시되지 않았다. 두 지표에 입력값이 없음을 확인한 뒤 채널 전체 범위로 전환했다.
- `channel` 측정 범위를 추가했다. 채널 바로 아래 일별 입력, 요약 드롭다운, 월간·연간 보고서에 연결한다. 소재나 광고 집행을 요구하지 않는다.
- 홈페이지 등 소재 없는 사용자 정의 채널에서 지표 추가를 누르면 채널 전체 범위를 기본으로 제안한다. 소재가 있는 채널에서도 측정 범위를 ‘채널 전체 · 소재 없이 기록’으로 선택할 수 있다.
- 채널 전체 지표는 소재 지표와 분리한다. 소재 생성 이후에도 채널 지표가 각 소재에 복제되거나 중복 합산되지 않는다. 채널별 비용 지표는 기존 선택 비용 합산을 사용한다.
- DB 검증 규칙에서 채널 전체 관측값은 소재·집행이 모두 없어야 하며 지표의 작업공간 검증은 유지한다. 기존 소재·광고·학원 입력 규칙을 보존한다.
- 실제 로그인 권한으로 비틀리 지표 저장·조회 및 잘못된 소재 연결 거부를 확인한 뒤 롤백했다. 테스트 값은 남기지 않았다.
- Migration: `20260914092829_channel_level_metrics.sql`. 기존 [유출 비밀번호 차단 미설정](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection) 외 새 보안 경고 없음.
