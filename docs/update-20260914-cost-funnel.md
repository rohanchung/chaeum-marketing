# 학원 성과 분류와 선택 비용 합산

- 학원 지표에 유입·상담·등록 집계 분류를 추가했다. 고정 키만 읽던 상단 합계를 분류별 합산으로 변경했다. 기존 설명회 신청은 유입, 당근 상담은 상담에 연결했다. 서로 중복되지 않는 활동 건수를 분류해 입력해야 하며 유일 인원 집계는 아니다.
- 현재 9월 기록에서 유입 6건·상담 1건을 집계한다. 등록은 미입력이며 0으로 추정하지 않는다.
- 소재 ROI 행과 채널·소재 드롭다운의 ROI, 활동 분석 표의 개별 ROI를 제거했다. 전체 매출 기반 ROI는 전체 분석·보고서에 유지한다.
- 인스타그램 바로 아래에 학원 전체 마케팅 성과를 추가했다. 총 마케팅 비용·상담·등록·상담당 비용·등록당 비용을 일별·월간으로 표시한다.
- 일별 금액 지표를 만들거나 수정할 때 마케팅 비용 포함 여부를 선택한다. 누적 금액이나 자동 계산 비율은 일별 지출로 합산하지 않는다.
- 기존 미디어·바이럴 비용 30,000원을 합산 대상으로 지정했다. 원시 값을 복사하지 않고 비용 원장 항목으로 함께 읽어 월·연간 보고서와 채널 집계에 한 번 반영한다. 원장 금액 수정도 원래 지표 값을 수정하며 빈칸 저장 시 해당 비용을 지운다.
- 지표를 삭제해도 합산하기로 한 과거 지출은 유지한다. 합산 선택을 해제하면 해당 지표의 과거 금액도 총비용에서 제외된다.
- 지표 추가는 ⊕ 아이콘으로 변경했다. 접근성 이름과 설명을 유지했다.
- DB migration: `20260914054702_metric_cost_and_funnel_roles.sql`. 예전 백업에 새 필드가 없어도 복원할 수 있도록 기본값을 보완한다.
- 내부 테스트 28개·타입·린트·배포 빌드 확인. DB에서 집계 분류와 30,000원 포함 설정을 재조회했다. 기존 보안 경고인 [유출 비밀번호 차단 미설정](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection) 외 새 보안 경고 없음.
