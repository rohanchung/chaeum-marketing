# 인스타 비용과 채널·소재 요약

- 인스타그램·검색 광고에도 당근과 같은 미설정 구간 입력을 적용했다. 소재를 펼치면 사전 기간 설정 없이 광고비를 입력할 수 있으며 비용 원장에 저장된다.
- 소재 아래에 일별·월간 ROI를 표시한다. 출처가 확인된 고객의 순수납과 수업 원가, 해당 소재 및 집행의 마케팅 비용을 기존 보고서 계산식으로 연결한다. 매출·원가 미입력 또는 비용 0이면 ROI는 미산정으로 표시한다.
- 채널·소재의 월간 요약 칸에 하위 지표 드롭다운을 추가했다. 선택한 지표의 월간 값과 날짜별 값은 하위 행을 접어도 표시된다. 선택은 현재 브라우저에 저장된다.
- 누적·마지막 관측 지표는 소재별 마지막 값을 합산한다. 비율은 원시값 합계로 계산하며 자식 비율을 더하거나 평균내지 않는다. 비즈프로필 지표는 해당 프로필 및 상위 채널에만 속한다.
- 비용·ROI 선택은 해당 대상에 연결된 비용 및 매출만 사용한다. 채널 공용 비용은 채널에 포함되며 소재에 임의 배분하지 않는다.
- 검증: 내부 테스트 24개, 인스타 광고비 DB 저장·조회 검증 후 롤백. 실제 운영 데이터와 DB 스키마 변경 없음.
