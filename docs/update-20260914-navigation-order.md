# 메뉴 이동 기록·채널 순서

- 대시보드·콘텐츠·이벤트·분석·리포트 메뉴 이동을 URL 해시와 브라우저 기록에 반영한다. 뒤로가기·앞으로가기로 이전 메뉴를 복원한다. 같은 메뉴 재선택은 기록을 추가하지 않는다. 직접 링크 및 새로고침도 해당 메뉴를 표시한다.
- 뒤로가기로 메뉴가 바뀔 때 열린 편집·상세 창을 닫는다. 앱 최초 진입 이전으로 돌아가는 기본 브라우저 동작은 유지한다.
- 채널 왼쪽 ⠿ 손잡이를 드래그해 다른 채널 앞뒤로 옮긴다. 손잡이에 키보드 초점을 두면 ↑↓도 지원한다. 소재·지표는 소속 채널과 함께 이동한다.
- 학원 전체 입력은 상단, 전체 마케팅 성과는 하단에 고정한다. 두 학원 패널은 드래그 대상에서 제외한다.
- 채널 순서는 DB에 저장한다. 새 채널은 기본적으로 뒤에 추가한다. 기존 데이터 및 색상은 유지한다. 예전 백업의 누락된 순서 필드는 복원 시 보완한다.
- Migration: `20260914080125_channel_display_order.sql`.
- 내부 테스트 30개: 메뉴 기록·뒤로/앞으로 전환 모사, 채널 재정렬·신규 채널·고정 패널 제외 및 기존 계산 회귀. 실제 로그인 권한으로 DB 순서 저장·조회 후 롤백했다. 브라우저 검증은 생략했다.
- 보안 점검은 기존 [유출 비밀번호 차단 미설정](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection) 외 신규 경고 없음.
