# 로한 마케팅 이름·채널 색상

- 앱 제목·상단·로그인·편집창·보고서·백업 파일명을 로한 마케팅으로 변경했다. 실제 학원 안내는 유지했다.
- 기본 favicon.ico를 제거하고 초록 바탕의 흰색 M SVG 파비콘으로 교체했다. 앱 로고에도 같은 M 모양을 사용한다.
- 채널 색상을 해당 채널·소재·집행·지표 행 전체와 고정 요약 열에 적용한다. 채널 22%, 소재 12%, 집행 8%, 지표 5% 농도로 위계를 구분하고 오늘 열은 더 강조한다.
- 기존 입력값과 DB 변경 없음.
- 타입 검사·린트·배포 빌드 통과. 정적 배포에 M 아이콘 경로가 생성됨을 확인했다.

Summary: 로한 마케팅 이름·M 파비콘 및 채널 색상 적용

Description:
- 앱 이름과 보고서·백업 표기를 로한 마케팅으로 변경
- 기본 파비콘을 M 모양 아이콘으로 교체
- 채널 색상을 전체 행에 적용하고 단계별 농도 구분
- 오늘 날짜 강조 및 기존 입력값 유지
