# 운영 시트 열 너비·지표 관리

- 운영 대상/지표, 월간 요약 열의 오른쪽 경계를 드래그해 너비를 조절한다. 경계에 키보드 초점을 두고 좌우 화살표로도 조절한다. 너비는 현재 브라우저에 저장한다.
- 월간 요약 기본 너비를 늘리고 고정 열 위치가 변경 너비를 따르도록 수정했다.
- 채널·소재의 지표＋ 버튼으로 지표를 추가하고 지표 이름을 눌러 수정한다. 비즈프로필의 사용자 정의 지표도 해당 프로필에만 표시한다.
- 지표 옆 ↑↓ 버튼으로 순서를 변경하고 DB에 저장한다. 동일한 채널·측정 그룹의 소재에 공통 적용된다. 중복 순번은 재정렬하며 프로필·광고·다른 채널은 섞지 않는다.
- ×는 지표를 소프트 삭제한다. 시트 도구 모음의 삭제한 지표에서 복원한다. 원시 입력값은 보존된다. 삭제된 원시 지표를 참조하는 계산 지표는 자료 없음으로 표시한다.
- DB에서 순서 변경·삭제·복원을 실제 로그인 권한으로 검증하고 입력값 전체 해시가 유지됨을 확인한 뒤 롤백했다. 운영 데이터 변경이나 스키마 변경은 없다.
- 내부 테스트 26개, 타입 검사·린트·배포 빌드 통과. 브라우저 검증은 생략했다.
