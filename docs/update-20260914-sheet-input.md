# 2026-09-14 소재 직접 입력·날짜 이벤트

- 소재 이름 클릭은 운영 시트 펼치기/접기로 변경. 상세·수정은 ⋯ 버튼으로 분리.
- 당근은 집행 기간이 없는 기존 소재도 지표 행과 날짜별 입력 칸을 제공한다. 새 소재에도 광고 기간 사전 입력을 요구하지 않는다.
- 첫 숫자 저장 시 해당 월의 미설정 구간을 광고 기록 대상으로 연결한다. 이미 지정한 기간과 기록은 유지한다. 빈 셀 지우기는 구간을 생성하지 않는다. 저장 대상 생성과 셀 저장은 순차 요청이라 셀 저장 실패 시 빈 구간이 남을 수 있으나 재시도에서 재사용한다.
- 노출·클릭·반응·도달·단골·관심·쿠폰 다운로드·지출 입력, CTR·CPC 자동 계산과 비용 원장 연결을 유지한다.
- 설명회·오프라인 채널은 시트 왼쪽에서 제외한다. 데이터 삭제 없이 기존 관리 화면·보고서에는 보존한다.
- 날짜 클릭으로 이벤트 추가, 기록된 날짜는 목록 조회·수정·삭제·추가. 시트 날짜 아래 제목 표시를 눌러 수정할 수 있다.
- 검증: 내부 회귀 테스트 21개, 타입 검사·변경 파일 린트·배포 빌드 통과. 실제 로그인 권한으로 광고 구간 생성→노출·지출 저장→재조회 검증 후 전체 롤백하여 테스트 데이터는 남기지 않았다. 브라우저 검증은 생략.
