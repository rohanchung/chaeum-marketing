# 당근 광고 입력과 컴팩트 운영 시트

## 변경

- 기존 ‘당근 광고’ 채널의 사용자 정의 설정을 당근 템플릿으로 연결했다. 기존 소재와 입력값은 유지한다.
- 노출·클릭·반응·도달·단골·관심·쿠폰 다운로드를 기록한다. 지출은 비용 원장과 동일한 기록이다. 클릭률·클릭당 비용·반응당 비용은 입력값에서 자동 계산한다.
- 당근·검색 광고 소재를 새로 만들 때 광고 시작일과 종료일을 함께 입력한다. 소재와 첫 집행은 하나의 DB 트랜잭션에서 저장한다.
- 이미 만든 소재에는 운영 시트 안에 ‘광고 지표 입력 · 기간 설정’을 표시한다. 기존 소재의 실제 집행 기간은 임의로 만들지 않았다. 사용자가 기간을 저장하면 지표 칸이 열린다.
- 첨부한 당근 성과 이미지를 입력 기준 안내에 포함했다. ‘최근 7일’ 합계와 일별 값을 구분하며, 반응 합계에 세부 반응을 다시 더하지 않는다. 도달은 월간 합계 대신 마지막 관측값이다.
- 상단 바 76→44px, 기본 입력 행 39→27px, 날짜 헤더 65→35px로 줄였다. 요약 카드를 좁은 띠로 줄이고 비용·매출 버튼을 시트 도구 모음으로 옮겼다.
- 서버 시각을 받아 한국 시간의 오늘 열 전체를 강조한다. 15초마다 날짜를 계산하고 5분마다 서버와 동기화한다. 탭에 다시 돌아오거나 포커스를 얻을 때도 재확인한다. 최초 서버 응답 전에는 기기 시간을 사용하며 ‘시간 확인 중’으로 표시한다.

## 검증

- 계산 테스트 18개 통과. 신규 검사는 한국 시간의 자정·연도 변경, 당근 원본 지표와 자동 비율, 도달 비합산을 포함한다.
- DB 검사: 템플릿, 서버 날짜, 소재·집행 동시 생성, 잘못된 날짜의 부분 저장 방지, 다른 채널 접근 차단, 조회 전용·익명 쓰기 차단 통과. 검사 트랜잭션은 롤백했다.
- 로그인한 브라우저에서 당근 소재 생성, 노출 1,000·클릭 20·지출 10,000 입력과 재조회를 확인했다. 클릭률 2%, 클릭당 비용 500원으로 계산됐다.
- 참고 이미지 로딩과 월 이동 후 오늘 강조를 확인했다. 서버와 화면 모두 2026-09-14를 표시했다. 자정 전환은 자동 테스트로 검증했다.
- TypeScript·ESLint·GitHub Pages 정적 빌드 통과.
- 검증용 소재·집행·값·비용만 지정 ID로 정리했다. 실제 소재 3개를 보존했다.
