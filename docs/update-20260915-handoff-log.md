# 제1차 제작방 핸드오프와 업데이트 로그

## 변경

- 리포트 오른쪽에 로그 메뉴(`#logs`)를 추가했다. 기존 메뉴와 동일하게 뒤로/앞으로 이동할 수 있다.
- 9월 13일 채널·퍼널 통합부터 당근, 인스타, 지표 관리, 비용 합계, 브랜딩, 채널 이동, 비틀리, 구매·이벤트 원가, 네이버 순위, 이번 인계까지 13건을 최신순으로 정리했다.
- 날짜·제목·제작방을 표시하고 펼치면 상세 변경점을 읽는다. 제목/날짜/내용 검색과 검색 결과 없음 안내를 제공한다.
- 로그에서는 업무 데이터 기간 선택 도구를 숨긴다. 이력은 날짜 필터에 의해 사라지지 않는다.
- 이력은 `web/src/lib/update-history.ts`에서 관리한다. 운영 데이터·DB를 변경하지 않는다. 과거 기능이 후속 업데이트에서 변경된 경우 그 사실을 명시했다.
- `docs/HANDOFF-PHASE1.md`에 제품 합의, 계산 원칙, 현재 기능, 코드·DB 위치, 검증 상태, 제한과 다음 방 진행 순서를 정리했다.
- `docs/HANDOFF-CURRENT.md`를 최신 인계 진입점으로 만들고 기존 HANDOFF-ASTRA에 역사 자료임을 표시했다.
- 루트 AGENTS.md에 다음 방의 인계 읽기, 매 업데이트 로그 갱신, 실제 데이터 보존, 비용 효율적인 검증, 사용자 GitHub Desktop 커밋/푸시 및 Summary/Description 제공 규칙을 남겼다.

## 검증

- 내부 테스트 36개 통과. 기존 메뉴 이동 검사에 리포트→로그→뒤로가기 복원을 포함했다.
- 변경 파일 ESLint, TypeScript 포함 GitHub Pages용 정적 빌드, 핸드오프 문서 링크 확인 통과.
- DB 변경·배포·커밋·푸시 없음. 브라우저 화면 조작은 생략하고 내부 검증했다.
