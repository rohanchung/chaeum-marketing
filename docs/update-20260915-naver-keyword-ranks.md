# 네이버 키워드 순위 기록

- 기존 네이버 블로그 채널을 네이버로 표시하고 기존 소재/지표/입력값은 유지.
- 대시보드 네이버 → 키워드 노출 → 키워드 → 모바일/PC·영역별 순위. 사용자 요청 검색어 ‘풍무동 채움영어’와 플레이스/홈페이지 모바일·PC 기본 정의만 생성. 실제 순위는 생성하지 않음.
- 키워드 노출의 ＋로 키워드 추가, 키워드를 클릭하면 날짜별 입력 행 표시. 키워드의 ⋯에서 이름·확인 대상 주소·표시할 영역 설정.
- 키워드의 ⊕로 순위 정의 추가, 지표 이름 수정/↑↓/삭제/복원 지원. 정의는 같은 채널 키워드에 공통이며 키워드별 표시 여부를 선택할 수 있음. 숨겨도 기존 값은 보존.
- 입력은 1 이상의 정수 또는 ‘미노출’. 0위는 없음. 미노출은 저장값 0이라는 내부 구분값으로 보관하고 UI/보고서에는 미노출로 표시. 빈칸은 미입력/기록 지우기.
- rank 전용 단위, latest 집계 고정. 월간 최근 순위, 직전 관측 대비 변화, 기간 최고 순위. 이전 관측은 전달도 포함하며 최고 순위는 선택 기간 내 양수 최솟값.
- 접힌 키워드의 드롭다운으로 대표 순위 선택. 서로 다른 키워드의 순위는 채널 합계에 더하지 않음. 광고비·클릭·퍼널 지표와 분리.
- 수동 일별 관측 기록이며 자동 검색/수집 기능은 없음. 기기·영역은 순위 정의 이름으로 구분. 광고 실행 시 광고 기능은 별도 업데이트.
- 기존 contents / mkt_metrics / mkt_values 및 RLS·일괄 저장·백업을 재사용. 서버에서 소수/음수 순위, 일반 소재에 순위 입력, 키워드에 일반 지표 입력, 순위의 합산 방식 변경 차단.
- 이전 백업에서 keyword_metric_ids가 누락되면 프론트 복원에서 현재 선택을 보존.
