# 소재 등록 과거순 정렬

- 운영시트와 콘텐츠 목록을 created_at 오름차순으로 정렬한다. 새 소재는 같은 채널/그룹 내 마지막에 표시한다.
- 기존 조회의 UUID 순서가 화면에 그대로 나타나던 문제를 수정했다. 발행일(published_at), 제목, 최근 수정일은 정렬에 사용하지 않는다.
- 같은 등록 시각은 id를 보조 기준으로 사용해 새로고침 시 순서를 고정한다. 등록 시각이 없는 예외 데이터는 뒤에 둔다.
- 키워드와 비즈프로필의 기존 그룹 배치는 유지하고, 각 그룹 내부는 등록순을 적용한다. 콘텐츠 페이지의 활성/아카이브/휴지통/검색 결과에도 동일하게 적용한다.
- 기존 데이터나 SQL 스키마 변경 없이 표시 순서만 변경. 로그와 최신 인계를 갱신했다.

## 검증

- 등록일과 발행일·ID 순서가 다른 경우 및 동일 시각의 시간대 표기가 다른 경우의 정렬 회귀 검사 포함.
- 내부 테스트38개, 변경 파일 ESLint, TypeScript 포함 정적 빌드 통과.
- 브라우저 조작 없이 내부 테스트·코드 검사·빌드로 검증한다. 커밋·푸시는 사용자가 GitHub Desktop에서 수행한다.
