# 운영시트 날짜 활동 패널

작성일: 2026-09-21
제작방: 현재 제작방

## 구현

- 운영시트의 날짜를 누르면 기존 이벤트만 보던 패널을 날짜 활동 패널로 확장했다.
- 해당 날짜의 실행 예정일 또는 마감일이 있는 Task를 업무 목록으로 표시한다.
- 패널에서 Task를 체크해 완료·미완료로 바꿀 수 있다.
- 선택한 날짜를 실행 예정일과 마감일로 미리 채운 업무 추가 폼을 열 수 있다.
- 이벤트 목록·직접 비용·이벤트 수정·신규 이벤트 기록은 기존 흐름을 유지했다.
- 운영시트 날짜 헤더의 Task 건수 표시와 활동 패널 내용을 같은 Task 원본에서 읽는다.

## 검증

- TypeScript 검사 통과.
- 변경 파일 ESLint 통과.
- 기존 analytics 테스트 38개 통과.
- Next 정적 빌드 통과.
- 브라우저 반복 검증은 실행하지 않았다.

## 제한

- 반복 업무의 회차 생성과 구글 캘린더 연동은 아직 구현하지 않았다.
- 날짜 활동 패널은 업무와 이벤트를 연결하며, 지표 셀 편집은 패널을 닫은 뒤 기존 운영시트에서 계속한다.
