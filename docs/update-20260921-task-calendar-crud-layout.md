# 캘린더·업무 목록 좌우 배치와 날짜 CRUD

## 반영 내용

- 업무 페이지를 좌측 캘린더·우측 업무 목록의 수평 구조로 고정했습니다.
- 캘린더와 업무 목록 패널의 상하 여백과 셀 높이를 줄여 한 화면에 더 많은 업무가 보이도록 조정했습니다.
- 캘린더 날짜 셀 자체와 날짜별 `＋` 버튼으로 해당 날짜의 새 업무를 만들 수 있습니다.
- 캘린더에 표시된 업무를 누르면 수정창이 열리고, 수정창에서 완료 처리와 삭제까지 이어집니다.
- 날짜 범위가 있는 업무는 실행 예정일부터 마감일까지 캘린더 칸에 이어서 표시합니다.

## 검증

- `npx tsc --noEmit`
- 변경 파일 ESLint
- 웹 단위 테스트 41개
- Next.js 프로덕션 빌드

이번 변경은 기존 업무와 마케팅 데이터 구조를 유지하며 화면 배치와 날짜별 업무 입력 흐름만 조정했습니다.
