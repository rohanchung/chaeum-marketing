# 대시보드 업무 영역 분리와 캘린더 중심 업무 화면

## 반영 내용

- 대시보드에서 오늘의 프로젝트 활동, 진행 중 프로젝트 요약, 날짜 활동 패널의 업무 목록·업무 추가 버튼을 제거했습니다.
- 대시보드는 KPI와 운영시트, 이벤트·마케팅 기록에 집중하고 업무 관리는 업무 페이지에서만 처리합니다.
- 업무 페이지는 월간 캘린더를 메인으로 배치하고 오른쪽에 프로젝트 하위 업무 목록을 표시합니다.
- 별도 타임라인 패널을 제거하고, 실행 예정일부터 마감일까지 업무가 캘린더 날짜 칸에 연속 표시되도록 통합했습니다.
- 날짜 칸에는 시작 업무와 이어지는 업무를 구분해 표시하고, 업무를 누르면 기존 편집창을 엽니다.

## 검증

- `npx tsc --noEmit`
- 변경 파일 ESLint
- 웹 단위 테스트 41개
- Next.js 프로덕션 빌드

이번 변경은 화면 구조만 조정하며 데이터베이스 스키마 변경은 없습니다.
