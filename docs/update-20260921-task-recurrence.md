# 반복 업무와 회차 기록

작성일: 2026-09-21
제작방: 현재 제작방

## 구현

- 업무 추가·수정 폼에 반복 업무 출처를 선택하고 매일·매주·매월, 간격, 반복 종료일을 설정할 수 있게 했다.
- 반복 업무는 원본 Task 하나에 다음 발생일을 보관하고, 오늘·날짜 활동 패널·업무 캘린더에서는 현재 회차 하나로 표시한다.
- 회차 완료 시 `mkt_task_occurrences`에 날짜별 완료 기록을 저장하고 원본 Task의 다음 발생일을 자동 계산한다.
- 반복 종료일을 지나면 새 회차를 만들지 않고 원본 업무를 완료 상태로 마무리한다.
- 대시보드 오늘 활동, 운영시트 날짜 활동 패널, 업무 목록·타임라인·캘린더의 완료 동작을 같은 회차 처리로 연결했다.
- 반복 업무 원본과 회차 기록에 작업공간 RLS 정책을 적용했다. 기존 마케팅 지표·비용·ROI 데이터는 변경하지 않는다.

## 검증

- Supabase 원격 마이그레이션 `20260921044648 task_recurrence` 적용 확인.
- 인증 작업공간 역할로 반복 Task 생성, 회차 완료, 다음 발생일 갱신을 트랜잭션 회귀 테스트했다.
- TypeScript 검사 통과.
- 변경 파일 ESLint 통과.
- 기존 analytics 테스트 38개 통과.
- 반복 규칙 단위 테스트 3개 통과.
- Next 정적 빌드 통과.
- Supabase 보안 advisor에서 기존 `auth_leaked_password_protection` 경고 외 새 경고가 없는 것을 확인했다.
