# 업무 페이지 계층·통합 보기 업데이트

## 반영 내용

- 저장 완료 안내를 화면 흐름을 밀어내는 문장이 아니라 우측 하단 자동 사라짐 토스트로 변경했습니다.
- 업무 페이지에서 프로젝트 업무 목록, 프로젝트 타임라인, 월간 캘린더를 한 화면에 함께 표시합니다. 필터는 데이터를 좁히고 보기 전환을 하지 않습니다.
- 프로젝트마다 접고 펼칠 수 있는 하위 업무 목록을 제공하고, 프로젝트 진행률과 시작일·목표일을 부모 행에 표시합니다.
- 프로젝트 행의 `＋ 업무`는 해당 프로젝트를 명시적으로 이어받고, 상단의 일반 업무 추가는 미분류로 시작합니다.
- 새 업무의 프로젝트 기본값을 최상단 프로젝트가 아닌 `미분류 업무`로 변경했습니다.
- 업무 행에 등록일, 실행 예정일, 마감일을 함께 표시합니다.
- 업무 추가·수정 시 선행 업무를 선택할 수 있으며, 선행 업무가 완료되지 않으면 `선행 대기` 상태와 연결된 업무명을 표시합니다.
