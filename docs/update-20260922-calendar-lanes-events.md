# 캘린더 날짜별 줄 배치와 이벤트 우선 표시

## 배경

같은 주 안에서 앞선 날짜의 일정 수만큼 이후 날짜 일정까지 아래 줄로 밀리는 문제가 있었습니다. 이벤트도 업무·프로젝트 바와 같은 우선순위로 배치되어 날짜 칸 상단에서 바로 보이지 않았습니다.

## 변경

- 주 단위 바 배치에 구간 충돌 검사를 적용했습니다. 서로 날짜가 겹치지 않으면 같은 줄을 재사용합니다.
- 이벤트 → 업무 → 프로젝트 순서로 줄을 배정해 이벤트가 해당 날짜의 최상단에 표시됩니다.
- 날짜 숫자 아래의 일정 시작 위치와 바 간격을 줄여 일정이 날짜 칸 상단에 붙도록 압축했습니다.

## 확인

- TypeScript 검사, ESLint, 41개 단위 테스트, 프로덕션 빌드, diff 공백 검사를 통과했습니다.
