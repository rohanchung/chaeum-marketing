# 업무 캘린더 레이아웃 재구성

## 문제

빈 날짜에 공통 `empty` 스타일이 적용되어 점선 카드처럼 보였고, 날짜 추가 버튼에는 일반 일정 버튼의 배경 규칙이 섞여 날짜마다 초록 막대가 나타났습니다. 일정 줄의 최소 높이도 화면의 남은 높이를 채우지 않아 캘린더 하단에 불필요한 빈 공간이 남았습니다.

## 변경

- 캘린더 외부 날짜 전용 클래스를 사용해 공통 빈 상태 스타일과 분리했습니다.
- 날짜 헤더, 선택 상태, 일정 바의 CSS 범위를 분리했습니다. 날짜는 좌상단에 두고 이벤트·업무·프로젝트 바는 그 아래에서 시작합니다.
- 월의 주 수에 맞춰 각 주가 화면의 남은 높이를 나눠 사용하도록 바꿨습니다.
- 데스크톱에서 캘린더와 선택 날짜 업무 목록이 같은 높이를 사용하게 했고, 상단 도구는 프로젝트 버튼과 업무 버튼까지 화면 안에 유지합니다.
- 이벤트는 캘린더와 오른쪽 업무 목록에서 업무보다 먼저 표시합니다.
