# 대시보드·업무 이벤트 공유

## 반영 내용

- 업무 페이지가 대시보드와 동일한 `marketing_events` 원본을 사용하도록 연결했습니다.
- 업무 캘린더에 시작일·종료일 기준 이벤트 기간 바를 표시합니다.
- 날짜를 선택하면 해당 날짜에 진행 중인 이벤트가 오른쪽 업무 목록에 함께 표시됩니다.
- 이벤트 바나 오른쪽 이벤트 항목을 누르면 기존 이벤트 편집 모달을 열 수 있습니다.
- 날짜별 오른쪽 목록의 `＋ 이벤트`로 이벤트를 만들 수 있으며, 저장한 내용은 대시보드 이벤트 목록·날짜 활동에 즉시 반영됩니다.
- 이벤트는 보라색 계열 바와 점으로 업무·프로젝트와 구분합니다.

## 검증

- `npx tsc --noEmit`
- 변경 파일 ESLint
- 웹 단위 테스트 41개
- Next.js 프로덕션 빌드

업무·대시보드 어느 쪽에서 작성해도 같은 이벤트 원본을 수정하므로 별도 복사본이나 중복 집계를 만들지 않습니다.
