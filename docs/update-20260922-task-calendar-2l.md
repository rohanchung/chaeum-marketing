# 업무 2L·한국 시각·캘린더 날짜 업무 흐름

## 반영 내용

- 업무 화면의 `WORKSPACE`와 설명 문구를 제거하고, 2L을 `업무` 제목·월 이동·오늘·프로젝트/업무 버튼·한국 현재 시각 한 줄로 정리했습니다.
- 업무 페이지에서 월 이동 버튼이 실제 캘린더 월을 변경하도록 연결했습니다.
- 서버 시계에서 보정한 한국 현재 시각을 2L에 표시하고, 업무 생성·완료·삭제 시각에 사용합니다.
- 월 첫날의 요일을 계산해 날짜와 요일이 실제 달력 위치에 맞도록 빈 칸을 포함해 렌더링합니다.
- 캘린더 그리드를 내부 스크롤 영역으로 만들어 마우스 휠로 캘린더를 위아래로 볼 수 있게 했습니다.
- 날짜를 선택하면 오른쪽 목록에 해당 날짜에 예정되거나 계속되는 업무만 표시합니다. 업무 아래에는 연결된 프로젝트명을 표시합니다.
- 날짜 셀과 날짜별 `＋` 버튼에서 해당 날짜 업무를 생성하고, 업무를 누르면 수정·완료·삭제할 수 있습니다.
- 오른쪽 목록에서 프로젝트 묶음 자체를 제거해 일자별 업무 흐름 중심으로 바꿨습니다.

## 검증

- `npx tsc --noEmit`
- 변경 파일 ESLint
- 웹 단위 테스트 41개
- Next.js 프로덕션 빌드

이번 변경은 기존 업무·프로젝트 데이터 구조를 유지하며 업무 화면과 시각 기준만 조정했습니다.
