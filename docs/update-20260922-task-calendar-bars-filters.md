# 업무 캘린더 연속 바·필터·프로젝트 색상

## 반영 내용

- 업무 화면의 동기화 상태를 업무 2L 아래 필터 바 옆으로 옮기고, 마지막 저장 시각을 서버 기준 한국 시각으로 표시합니다.
- 오늘·요청받은 업무·반복 업무·프로젝트 필터는 여러 개를 동시에 선택할 수 있으며, 선택한 조건에 맞는 업무만 캘린더와 오른쪽 목록에 표시합니다. 전체를 누르면 필터를 초기화합니다.
- 기간이 있는 업무는 날짜마다 별도 항목을 반복하지 않고 주 단위로 이어지는 색상 바로 표시합니다. 업무 바의 색상은 연결된 프로젝트 색상을 사용합니다.
- 프로젝트 추가·수정 모달에 RGB 색상 선택기를 추가하고 `mkt_work_projects.color` 컬럼과 형식 제약을 적용했습니다.
- 캘린더를 화면 높이에 맞춰 확장하고, 업무·프로젝트 및 기존 편집 모달의 ESC 취소·Enter 저장 동작을 유지합니다.

## 데이터베이스

- Supabase migration `20260922023930_work_project_colors` 적용
- 기존 프로젝트의 색상은 기본값 `#4e986e`로 채워집니다.

## 검증

- `npx tsc --noEmit`
- 변경 파일 ESLint
- 웹 단위 테스트
- Next.js 프로덕션 빌드

이번 변경은 프로젝트·업무 데이터만 보강하며 대시보드의 마케팅 지표·비용·ROI 계산에는 영향을 주지 않습니다.
