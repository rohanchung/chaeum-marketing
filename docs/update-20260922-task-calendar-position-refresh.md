# 업무 추가 실시간 표시와 날짜 바 위치 수정

## 원인

캘린더의 연속 업무 바를 절대 위치로 그리면서 날짜별 시작 위치와 기간 너비를 적용하지 않아, 다른 날짜에 추가한 업무도 같은 칸에 겹쳐 보였습니다. 저장된 업무 자체가 일별 개수로 제한된 것은 아니었습니다.

## 수정 내용

- 업무 바마다 주간 그리드의 시작 열과 종료 열을 기준으로 `left`와 `width`를 계산합니다.
- 같은 날짜에 업무를 여러 건 추가해도 각 업무가 별도 줄로 계속 표시됩니다.
- 저장 후 기존 `refresh` 흐름으로 Supabase 원본을 다시 읽어 새 업무와 오른쪽 날짜 목록을 갱신합니다.
- 다른 날짜에 업무를 추가하면 해당 날짜 칸에만 업무 바가 나타납니다.
