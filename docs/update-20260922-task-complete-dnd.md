# 업무 완료 표시와 캘린더 실행일 이동

## 반영 내용

- 완료 체크한 업무를 목록 아래로 이동하지 않고 같은 위치에 유지합니다.
- 완료 업무는 투명도와 채도를 낮추고 제목에 가운데 줄을 표시해 처리 상태를 구분합니다.
- 캘린더의 일반 업무 바를 날짜 칸으로 드래그하면 실행 예정일이 해당 날짜로 저장됩니다.
- 실행일과 마감일이 모두 있는 기간 업무는 기존 기간 일수를 유지한 채 마감일도 함께 이동합니다.
- 반복 업무 회차, 프로젝트 기간 바, 이벤트 기간 바는 드래그 이동 대상에서 제외합니다.
- 드래그 중인 날짜 칸은 점선과 연한 초록 배경으로 표시합니다.

## 검증

- `npx tsc --noEmit`
- 변경 파일 ESLint
- 웹 단위 테스트 41개
- Next.js 프로덕션 빌드

완료·이동 기록은 기존 서버 기준 시각과 `mkt_tasks` 원본을 그대로 사용합니다.
