# 캘린더 휠 월 전환과 업무 2L 통합

## 반영 내용

- 업무 캘린더 위에서 마우스 휠을 아래로 움직이면 다음 달, 위로 움직이면 이전 달로 전환합니다.
- 한 번의 휠 동작에 한 달만 전환되도록 짧은 입력 잠금을 적용했습니다.
- `오늘`, `전체`, `요청받은 업무`, `반복 업무`, `프로젝트` 토글과 저장 상태를 `업무` 제목 바로 옆 2L에 통합했습니다.
- 날짜 이동·오늘·업무 추가·프로젝트 추가 버튼은 2L 오른쪽에 유지합니다.
- 별도 L3 필터 행을 제거해 캘린더의 시작 위치와 화면 사용 높이를 확보했습니다.
