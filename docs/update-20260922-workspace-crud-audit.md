# 업무·프로젝트·이벤트 CRUD 점검

## 점검 결과

| 대상 | 생성 | 조회 | 수정 | 삭제 |
| --- | --- | --- | --- | --- |
| 업무 | 상단·날짜별 추가 | 캘린더·선택 날짜 목록 | 수정창·완료·드래그 이동 | 수정창 휴지통 |
| 프로젝트 | 상단 추가 | 프로젝트 기간 바 | 프로젝트 수정창 | 프로젝트 수정창 휴지통 |
| 이벤트 | 선택 날짜 추가 | 이벤트 기간 바·선택 날짜 목록 | 이벤트 수정창 | 이벤트 수정창 휴지통 |

## 변경

- 공용 수정창에 기존 기록을 휴지통으로 옮기는 동작을 추가했습니다. 따라서 업무 캘린더에서 연 이벤트도 같은 수정창에서 삭제할 수 있습니다.
- 프로젝트 수정창에도 휴지통 동작을 추가했습니다.
- 삭제는 원본을 지우지 않는 소프트 삭제입니다. 프로젝트를 삭제해도 이미 연결된 업무 기록은 유지됩니다.

## 확인

- TypeScript 검사, ESLint, 41개 단위 테스트, 프로덕션 빌드, diff 공백 검사를 통과했습니다.
