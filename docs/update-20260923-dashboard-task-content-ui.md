# 대시보드·업무·콘텐츠 운영 화면 정리

## 변경

- 대시보드는 상단 핵심 성과 요약과 하단 운영시트를 중심으로 다시 정리했습니다. 기존 입력과 비용·매출·퍼널 데이터는 그대로 유지합니다.
- 업무 페이지는 데스크톱에서 캘린더와 선택 날짜의 업무 카드를 수평으로 나란히 보이게 하고, 화면 폭이 좁아질 때만 세로로 전환합니다.
- 콘텐츠 페이지는 카드 모음 대신 채널별 표로 재구성했습니다. 소재별 대표 지표·월간 값·월간 비용을 한 줄에서 비교할 수 있습니다.
- Bitly처럼 소재 없이 채널 자체 지표만 기록하는 채널도 같은 표에 `채널 자체 지표` 행으로 표시합니다. 대표 지표를 고르고 상세 값을 펼쳐 확인할 수 있습니다.
- 기존 채널·소재·지표 관리 CRUD는 콘텐츠 화면의 `채널·지표 관리` 접이식 영역에 유지했습니다.

## 데이터 영향

- 데이터베이스 스키마와 기존 기록은 바꾸지 않았습니다.
- 기존 콘텐츠·채널·소재 지표와 업무·프로젝트·이벤트 데이터를 현재 저장 구조에서 그대로 읽습니다.

## 검증

- TypeScript, ESLint, 단위 테스트, 프로덕션 빌드, diff 공백 검사를 실행했습니다.
- 실제 화면에서 대시보드의 운영시트, 업무의 캘린더·선택일 목록 수평 배치, 콘텐츠의 채널 그룹 표를 시안과 비교해 확인했습니다.
