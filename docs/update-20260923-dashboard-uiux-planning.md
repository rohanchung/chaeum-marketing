# 대시보드 UI/UX 개편 기획 초안

작성일: 2026-09-23

## 결정

- 대시보드를 Football Manager처럼 표·그룹·요약 행 중심으로 확장 가능한 마케팅 운영 화면으로 재정의했다.
- 기존 월간 KPI와 가로 날짜 운영 시트라는 골격은 유지한다.
- 업무·프로젝트·체크리스트는 대시보드에 다시 넣지 않는다.
- 구현 전 기획 문서 검토와 사용자 승인을 먼저 받는다.

## 현재 구성 확인

- 대시보드는 월 선택, 저장 상태, 빠른 입력, KPI 5개, 가로 날짜 운영 시트로 구성되어 있다.
- 운영 시트는 학원 전체 퍼널, 이벤트, 채널·소재·광고·키워드 지표, 학원 전체 마케팅 성과를 한 표에서 처리한다.
- 날짜별 직접 입력, 자동 계산, 오늘 강조, 붙여넣기, 키보드 이동, 채널·지표 정렬과 열 너비 조절이 이미 구현되어 있다.

## 검증

- `web/src/app/page.tsx`, `web/src/components/operating-sheet.tsx`, `web/src/app/globals.css`를 읽어 현재 렌더 구조와 상호작용을 대조했다.
- 문서 변경만 수행했으며 애플리케이션 코드·DB·운영 데이터는 수정하지 않았다.

## 제한

- 이 문서는 구현 승인 전 초안이다. 실제 화면 변경, 데이터 계약 변경, 테스트·빌드는 아직 수행하지 않았다.
- 기존 `ui-design-spec.md`는 초기 설계 기록으로 보존하며, 대시보드 개편 판단에는 이 문서와 최신 사용자 지시를 우선한다.
