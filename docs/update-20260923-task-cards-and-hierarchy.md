# 날짜별 업무 카드와 하위 업무 연결

## 변경

- 선택한 날짜의 업무를 카드로 표시합니다. 카드 본문을 누르면 업무 상세를 열고, 체크박스는 완료 상태만 바꿉니다.
- 카드를 위쪽 또는 아래쪽 가장자리에 놓으면 같은 단계에서 순서를 바꿉니다.
- 카드 중앙에 놓으면 드래그한 업무가 대상 카드의 하위 업무가 됩니다. 순환 관계는 만들지 않습니다.
- 새 업무에는 정렬 순서를 부여해 드래그로 정한 순서가 다음 조회에도 유지됩니다.
- 업무 상세 맨 아래의 `다음 업무` 입력은 현재 업무의 프로젝트·예정일을 이어받는 하위 업무 생성으로 연결했습니다.

## 확인

- TypeScript 검사, ESLint, 41개 단위 테스트, 프로덕션 빌드, diff 공백 검사를 통과했습니다.
