# 채널명 중복 저장 안내

## 문제

- 같은 워크스페이스에 이미 있는 채널명을 다시 저장하면 데이터베이스의 고유 키 제약이 거절했습니다.
- 화면에는 `duplicate key value violates unique constraint`라는 SQL 오류가 그대로 노출됐습니다.

## 변경

- 채널 추가·수정 모달에서 저장 전에 공백과 대소문자를 정리한 채널명을 비교합니다.
- 활성 채널과 겹치면 기존 채널 수정 또는 다른 이름 입력을 안내합니다.
- 휴지통 채널과 겹치면 복원 또는 이름 변경을 안내합니다.
- 서버에서 같은 충돌이 돌아와도 기술 오류 대신 한국어 안내를 표시합니다.

## 검증

- 채널명 중복·휴지통 중복·현재 채널 자신의 이름 유지·새 이름을 검증하는 단위 테스트를 추가했고 통과했습니다.
- TypeScript, ESLint, 단위 테스트 43개, 프로덕션 빌드와 diff 공백 검사를 통과했습니다.
- 채널·지표·기존 운영 데이터와 Supabase 스키마는 변경하지 않습니다.
