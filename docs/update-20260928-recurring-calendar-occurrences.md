# 반복 업무 월간 회차 표시

## 문제

- 반복 업무는 `recurrence_next_on`의 다음 한 회차만 가상 업무로 만들었습니다.
- 매일 또는 N일 간격으로 지정해도 현재 날짜 한 건만 보이고, 뒤 날짜에는 반복 업무가 표시되지 않았습니다.

## 변경

- 현재 보고 있는 달의 시작일과 종료일 사이에 포함되는 반복 회차를 계산해 캘린더 바와 선택일 업무 목록에 모두 표시합니다.
- 기존의 매일·N일마다·매주·매월·종료일 규칙을 그대로 사용하며, 미래 달을 열면 해당 달 회차를 새로 계산합니다.
- 미래 회차의 완료 처리는 차단해 미래 일을 체크했을 때 앞선 회차까지 건너뛰는 문제를 막았습니다.

## 후속 UI 설계

- 반복 규칙에는 `주말 제외`와 `영업일 N일 간격`을 별도 옵션으로 추가할 예정입니다. 이 설정은 반복 원본에 저장돼 완료 후 다음 회차 계산과 월간 표시 모두에 동일하게 적용됩니다.

## 검증

- 반복 업무가 2026-09-28부터 시작하면 9월 캘린더에 28·29·30일 회차가 생성되는 단위 테스트를 추가했고 통과했습니다.
- TypeScript, ESLint, 단위 테스트 42개, 프로덕션 빌드와 diff 공백 검사를 통과했습니다.
- Supabase 스키마와 기존 업무 데이터는 변경하지 않습니다.
