# 업무 캘린더 마지막 주 표시 보완

## 문제

- 업무 화면은 공용 도구 행을 렌더링하지 않아도 빈 행의 높이와 여백을 차지하고 있었습니다.
- 그 공간만큼 캘린더가 아래로 밀려, 5주차인 28~30일의 일정 바가 화면 아래에 잘렸습니다. 입력한 업무가 없는 것처럼 보일 수 있었습니다.

## 변경

- 업무·콘텐츠 화면에서는 비어 있는 공용 도구 행을 렌더링하지 않습니다.
- 업무 화면은 상단 바와 작업 영역을 제외한 높이를 캘린더와 선택일 업무 목록이 나누어 쓰도록 변경했습니다.
- 주별 최소 높이를 고정값 대신 표시할 일정 바 수에 맞춰 계산했습니다. 마지막 주와 6주차 달에서도 업무 바에 필요한 높이를 우선 확보합니다.

## 검증

- TypeScript, ESLint, 단위 테스트 41개, 프로덕션 빌드, diff 공백 검사를 통과했습니다.
- 데이터 저장 방식과 Supabase 스키마는 변경하지 않았습니다.
