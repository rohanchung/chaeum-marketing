# 업무 캘린더 화면 높이 반응형 조정

## 문제

- 마지막 주를 보이게 하려고 설정한 고정 최소 높이 때문에 창 높이가 작은 환경에서 5주차·6주차가 화면 아래로 다시 밀렸습니다.
- 캘린더 전체가 페이지 바깥으로 커져 마지막 행을 바로 확인할 수 없었습니다.

## 변경

- 데스크톱 업무 화면은 상단 헤더를 제외한 브라우저 높이를 작업 영역으로 사용합니다.
- 캘린더와 오른쪽 선택일 업무 목록이 그 영역을 함께 채우고, 달의 주 행은 남은 높이를 균등하게 나눕니다.
- 일정 바가 많은 달만 캘린더 내부 스크롤을 사용하므로 행이 조용히 잘리지 않습니다.

## 검증

- TypeScript, ESLint, 단위 테스트 42개, 프로덕션 빌드와 diff 공백 검사를 통과했습니다.
- 업무·이벤트 데이터와 Supabase 스키마는 변경하지 않습니다.
