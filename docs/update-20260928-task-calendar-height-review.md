# 업무 캘린더 5주차 검수 수정

## 검토 결과

- 마지막 주 보완 뒤의 실제 화면에서 캘린더는 1~26일의 네 행만 보이고, 27~30일 행이 통째로 캔버스 밖으로 잘렸습니다.
- 오른쪽 선택일 목록에는 28일 업무 두 건이 정상적으로 표시돼 저장·조회 문제가 아니라 캘린더 레이아웃의 높이 충돌임을 확인했습니다.
- 원인은 캘린더 바깥 컨테이너를 flex로 바꾸면서 캘린더의 `height`와 `min-height`를 `auto`·0으로 덮어쓴 것이었습니다.

## 수정

- flex 축소 규칙을 제거하고, 업무 캘린더는 grid 기반의 화면 높이와 최소 높이를 다시 사용합니다.
- 데스크톱에서 캘린더·오른쪽 업무 목록 영역은 최소 560px, 실제 날짜 캔버스는 최소 500px을 확보합니다.
- 각 주는 최소 66px을 사용하며, 표시할 업무·이벤트 바가 많으면 필요한 만큼 더 높아집니다.

## 검증

- TypeScript, ESLint, 단위 테스트 41개, 프로덕션 빌드, diff 공백 검사를 통과했습니다.
- 데이터 저장 방식, Supabase 스키마, 업무·이벤트 CRUD 동작은 변경하지 않았습니다.
- Node 내장 테스트에서 사용하는 기존 CommonJS import는 테스트 파일에서만 ESLint 예외로 처리했습니다.
