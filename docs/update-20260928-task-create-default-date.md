# 상단 업무 추가의 날짜 기본값

## 문제

- 상단 `＋ 업무`는 실행 예정일과 마감일을 비운 채 편집창을 열었습니다.
- 데이터베이스는 날짜 없는 업무를 저장할 수 있지만, 업무 캘린더와 선택일 목록은 기간이 있는 업무만 표시합니다. 따라서 저장된 업무가 화면에서 사라져 생성 실패처럼 보였습니다.

## 변경

- 상단 `＋ 업무`는 오늘을 실행 예정일·마감일의 기본값으로 엽니다.
- 새 업무에서 두 날짜를 지우고 저장해도 오늘 일정으로 저장합니다.
- 한쪽 날짜만 입력한 새 업무는 입력한 날짜를 시작일·마감일 모두에 사용합니다.
- 기존 날짜 없는 업무는 수정만으로 날짜가 자동 입력되지 않습니다.

## 검증

- TypeScript, ESLint, 단위 테스트, 프로덕션 빌드와 diff 공백 검사를 실행합니다.
- Supabase 스키마와 기존 업무 데이터는 변경하지 않습니다.
