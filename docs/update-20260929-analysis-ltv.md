# 분석 > 장기 수익성 (LTV·CAC)

기획: [장기 관점의 마케팅 비용 계산 기획](plan-20260929-ltv-marketing-cost.md) — 기본값 10장.

## 배경

학생은 매달 수강료(20~30만 원)를 내고 1년이면 240~360만 원이 된다. 같은 달 비용과 매출을 맞대는 기존 ROI로는 오픈 초기 마케팅이 항상 적자로 보여, 학생 한 명 단위로 비용 회수를 보는 화면을 분석 페이지에 추가했다(로한: "분석 페이지 업데이트", 수강료는 칸만 열고 값은 로한이 입력).

## 변경

### 입력 칸 (DB: `20260929094950_ltv_analysis_inputs`)

- 고객(학생) 기록: **월 수강료**, **퇴원일**. 비워 둘 수 있다. 퇴원일은 신규 등록일 이후만 허용.
- 비용 기록: **비용 성격** `신규 획득 / 개원·브랜딩(1회성) / 재원생 유지`. 기존 비용·운영시트 광고비는 비어 있으며 신규 획득으로 계산.
- 가정값 테이블 `mkt_ltv_settings`(작업공간당 1행, 없으면 기본값). 조회는 멤버, 수정은 소유자·편집자.
- 모든 새 칸은 비워 둘 수 있어 기존 데이터와 예전 JSON 백업 복원에 영향이 없다. 가정값 테이블은 백업 내보내기·복원 목록에 추가.

### 분석 > 장기 수익성 탭

- 지표 5개: 등록당 획득비(CAC = 신규 획득 비용 ÷ 신규 등록), 1인 월 공헌이익(입력된 월 수강료 평균 × 공헌이익률), LTV(가정/실측 표시), LTV:CAC(적정·주의·점검), CAC 회수 기간.
- 신규 등록 수는 학원 전체 퍼널 값을 쓰고, 퍼널이 비어 있으면 고객 기록의 등록 수를 쓴다.
- 월 수강료가 없으면 LTV를 추정하지 않고 `고객·전환 기록으로` 안내를 띄운다.
- 유지 기간 시나리오(기본 6 / 확장 12 / 낙관 18개월)와 목표 비율 기준 CAC 상한.
- 비용 성격별 지급액과 개원 비용 누적 회수율.
- 등록월별 회수 표: 그 달 신규 획득비 대비 그 달 등록 학생의 누적 공헌이익(실제 수납 × 공헌이익률), 회수된 개월 차.
- 채널별 획득 효율: 최근 3개월, 확인된 출처(고객 답변·직접 확인)만, 신규 5명 미만은 `표본 부족`.
- 가정값 설정: 공헌이익률 40%, 기대 유지 6개월, LTV 상한 24개월, 목표 3:1, 회수 3개월(기본값으로 되돌리기 가능).
- 실측 전환: 첫 등록 후 6개월이 지나면 기대 유지 기간을 실제 퇴원율(학생-개월 대비 퇴원 수)로 계산하고 `실측`으로 표시.

### 기존 화면

- `기간 마케팅 ROI` → **`당월 현금 ROI`**(분석·리포트·Excel/인쇄 보고서). 설명: 이번 기간 수납·비용만 비교한 단기 지표. 계산식은 그대로.
- 비용 원장 표에 `성격`, 고객·전환 표에 `월 수강료`·`퇴원` 열.

## 검증

- 단위 테스트 70개(신규 `ltv.test.cjs` 7개: CAC 비용 성격 분리, 기본값 60만·3:1·2개월, 수강료 미입력 시 미계산, 판단 구간, 실측 전환 조건, 코호트 회수, 채널 표본 부족), TypeScript, ESLint, 프로덕션 빌드 통과.
- `supabase/tests/ltv_inputs.sql`: 가정값 저장·수정, 수강료·퇴원일 저장, 등록 전 퇴원 거부, 비용 성격 저장을 원격 DB에서 실행 후 롤백(잔여 0건 확인).
- 화면(실제 데이터): 장기 수익성 탭 표시, 9월 신규 획득 비용 1,823,861원 집계, 수강료 미입력 안내, 입력 창·표의 새 칸 확인(저장 없이).

## 제한

- 현재 학생·수납 기록이 0건이라 CAC·LTV는 값이 들어오기 전까지 `—`로 표시된다.
- 공헌이익률은 결제별 서비스 원가 대신 설정값 하나를 쓴다. 결제별 서비스 원가는 기존 당월 현금 ROI에만 쓰인다.
