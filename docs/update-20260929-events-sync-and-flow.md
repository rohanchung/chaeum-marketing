# 이벤트 표시 기준 통일·결과 메모 바로 쓰기·흐름 페이지

## 1. 이벤트 연동

### 문제 (로한: "만든 이벤트가 안 보임", "상태·내용이 다름")

모든 화면이 같은 `marketing_events` 테이블을 쓰지만, 화면마다 거르는 기준이 달랐습니다.

| 화면 | 여러 날 이벤트 | 상태 |
|---|---|---|
| 업무 캘린더·목록 | 기간 전체 | 표시 |
| 이벤트 페이지 | 기간 전체 | 표시(정렬 없음) |
| 대시보드 시트·날짜 창 | **시작일에만** | **표시 안 함** |

### 변경

- `lib/events.ts` 하나로 기준 통일: 이벤트는 시작일~종료일(없으면 시작일) 모든 날에 표시, 기간과 겹치면 그 기간에 포함, 시작일 순 정렬.
- 대시보드 시트 이벤트 행·날짜 머리 점·월 건수, 날짜별 기록 창, 업무 캘린더·목록, 이벤트 페이지가 모두 이 기준을 씁니다.
- 완료 체크(완료↔예정)를 업무 화면에 더해 **이벤트 페이지 카드와 대시보드 날짜 창**에도 달았습니다. 완료 이벤트는 모든 화면에서 흐림·취소선.
- 대시보드 이벤트 표시의 툴팁에 상태를 보여 줍니다. 이벤트 페이지에는 종료일이 있으면 `~MM/DD`를 붙입니다.

## 2. 결과 메모 바로 쓰기 (이벤트 카드)

- 이벤트 페이지 카드의 결과 메모를 카드에서 바로 입력합니다. 다른 곳을 누르면(포커스가 빠지면) 저장되고, 내용이 바뀌지 않았으면 저장하지 않습니다.
- 휴지통 이벤트의 메모는 수정할 수 없습니다.

## 3. 흐름 페이지 (신규)

로한 요청: 해야 할 일을 적고, 앞 일·뒤 일을 이어 붙여 파생되는 일과 날짜까지 정리한 뒤, 저장하면 업무 페이지에 반영.

### 결정

- **가지치기형**: 업무마다 앞 일은 하나, 뒤 일은 여러 개. 앞 일은 기존 `depends_on_task_id`(업무 페이지의 상위 업무)를 그대로 써서 DB 구조 변경이 없습니다. 두 갈래가 한 일로 합쳐지는 구조는 지원하지 않습니다.
- **프로젝트별**: 왼쪽에서 프로젝트(또는 미분류 업무)를 고르면 그 업무들이 흐름도로 나옵니다. `＋ 프로젝트`로 새 프로젝트를 만들 수 있습니다.
- 화면은 벤다이어그램 대신 **박스와 화살표로 잇는 흐름도**(왼쪽→오른쪽)입니다.

### 사용법

- `＋ 시작 업무`: 새 갈래의 첫 업무.
- 카드의 `＋ 뒤 일`: 이어지는 업무(앞 일의 마감일을 기본 날짜로). `＋ 앞 일`: 이 업무와 기존 앞 일 사이에 끼워 넣기. `앞 일 연결`: 다른 카드를 눌러 앞 일로 지정(Esc 취소, `앞 일 없음`으로 떼기). 자기 뒤에 이어진 업무는 고를 수 없습니다.
- 카드에서 제목·실행일·마감일·완료를 바로 수정. `✕`는 흐름에서 빼고 저장 시 휴지통으로 옮기며, 뒤 일은 앞 일에 다시 이어집니다.
- 편집은 저장 전까지 화면에만 있습니다. `저장`을 누르면 바뀐 업무만 **한 번의 요청**으로 저장되어 업무 페이지에 바로 반영됩니다(모두 저장되거나 하나도 저장되지 않음). `변경 취소`로 되돌립니다. 저장하지 않고 다른 메뉴·프로젝트로 가면 확인을 묻습니다.
- 새 업무는 출처 `내가 만든 업무`, 상태 `예정`, 선택한 프로젝트의 업무 영역으로 저장됩니다. 기존 업무의 완료 시각·업무 영역·출처는 유지합니다.

### 구현

- `lib/task-flow.ts`: 초안·앞/뒤 추가·연결·순환 검사·삭제·배치·저장 행 계산(순수 함수).
- `components/flow-workspace.tsx`: 화면. `lib/repository.ts`의 `saveTaskFlow`: 일괄 upsert.
- 메뉴에 `흐름`(업무 다음, `#flow`) 추가. 흐름 화면은 기간과 무관해 헤더 날짜 컨트롤을 숨깁니다.

## 검증

- 단위 테스트 63개(신규: `events.test.cjs`, `task-flow.test.cjs`), TypeScript, ESLint, 프로덕션 빌드 통과.
- 원격 DB에서 롤백 트랜잭션으로 확인: 한 요청 안에서 뒤 일이 앞 일보다 먼저 와도 저장되고, 한 행이라도 제약에 걸리면 전체가 저장되지 않습니다.
- 화면(실제 데이터, 저장 없이): 흐름도 표시, 뒤 일/앞 일 추가, 순환 연결 차단, 빈 제목 저장 차단, 변경 취소. 이벤트 페이지·대시보드의 상태 일치.

## 제한

- 휴지통에 들어간 프로젝트에 연결된 업무(현재 `버스정류장 광고 세팅`)는 흐름 목록에 나오지 않습니다. 업무 페이지에서 프로젝트를 바꾸면 흐름에 나타납니다.
- 반복 업무는 반복 원본 하나가 카드 하나로 나옵니다.
