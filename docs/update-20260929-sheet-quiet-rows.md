# 운영시트 행 도구 정리 (4단계 · 대시보드 개편안 1단계 잔여)

계획: [단계별 업데이트 계획](plan-20260929-uiux-update-roadmap.md) · 기준: [대시보드 개편안](dashboard-uiux-plan.md) 4.2, 5.5

## 문제

- 지표 행마다 `↑ ↓ ×`, 채널·소재 행마다 `⋯ ＋ ⊕`가 항상 보여 시트가 산만했습니다.
- `삭제한 지표` 버튼이 시트 상단에 상시 노출됐습니다(개편안은 `⋯ 더보기`).
- 월간 요약 칸에서 대표 지표 선택 문구가 줄바꿈되고 값이 아랫줄로 밀렸습니다.

## 변경

- 행 도구는 행에 마우스를 올리거나 키보드 포커스가 들어올 때만 보입니다. 터치 기기(hover 없음)에서는 항상 보입니다. 기능과 위치는 그대로입니다.
- 시트 상단의 `삭제한 지표`를 `⋯` 메뉴로 옮기고 안쪽 제목을 `삭제한 지표 복원`으로 붙였습니다.
- 월간 요약 칸은 한 줄입니다: 왼쪽에 대표 지표 선택(길면 말줄임, 전체 이름은 툴팁), 오른쪽에 값.

## 유지

- 데이터 구조, 집계, 입력·붙여넣기·되돌리기 동작은 바꾸지 않았습니다.

## 검증

- TypeScript, ESLint, 기존 단위 테스트 통과.
