# 업무 캘린더 가변 주 높이·`+N개` 표시와 Shift+휠 월 전환 (1단계)

계획: [단계별 업데이트 계획](plan-20260929-uiux-update-roadmap.md)

## 문제

- 주 행의 높이를 일정 수에 맞춰 늘리는 구조였습니다. 창이 낮으면 캘린더가 넘쳐 안쪽 스크롤이 생겼는데, 휠이 월 전환에 쓰여 마지막 일정을 볼 수 없었습니다(1366×640에서 확인).
- 09-28에 같은 잘림을 세 번 고치는 동안 `.calendar-main .calendar-grid` 규칙이 `globals.css`에 8번 덮어쓰기로 쌓였습니다.
- 캘린더 일정 바와 보조 텍스트가 9px였습니다.
- 헤더·캘린더 제목줄·패널 여백이 캘린더 위 약 190px을 차지했습니다.

## 변경

- **가변 주 높이(로한 피드백 반영):** 일정이 적은 주는 2줄 높이로 작게, 많은 주는 **최대 10줄**까지 늘어납니다. 11개째부터는 날짜별 `+N개`로 접히고, 누르면 그 날짜 목록이 열립니다. 남는 높이는 모든 주가 나눠 쓰고, 전체가 화면보다 크면 캘린더 안에서 일반 휠로 스크롤합니다.
- 월 전환은 `Shift + 휠`로만 동작합니다. 브라우저가 Shift+휠을 가로 휠로 보내도 인식합니다.
- **캘린더 위 공간 축소:** `○월 업무 캘린더` 제목줄을 없애고(화면낭독용 제목만 유지, 사용 안내는 캘린더 툴팁), 업무 헤더와 패널 여백을 줄여 요일줄을 헤더 바로 아래에 붙였습니다.
- 캘린더 크기 규칙 8개를 지우고 `globals.css`의 캘린더 블록 하나로 모았습니다.
- 일정 바·보조 텍스트는 최소 11px입니다. 헤더 시계는 초 단위를 없애고 분 단위로 표시합니다.
- 주별 구간·레인 배치·주 높이·`+N` 계산을 `lib/task-calendar.ts` 순수 함수로 분리했습니다.

## 검증

- `tests/task-calendar.test.cjs`: 주 구간 자르기, 레인 배치, 10줄 제한과 `+N` 개수, 기본·확장 주 높이.
- TypeScript, ESLint 통과. 화면 확인 범위는 보고 답변에 별도로 적습니다.
