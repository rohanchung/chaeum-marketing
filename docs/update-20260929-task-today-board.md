# 오늘 보드와 업무 카드 정리 (2·3단계)

계획: [단계별 업데이트 계획](plan-20260929-uiux-update-roadmap.md)

## 문제

- 요구사항 5.1의 “오늘 마감·오늘 실행·기한 초과·반복 업무를 한 화면에서”가 구현되지 않았습니다. 오른쪽 목록은 선택한 날짜만 보여 줬고, 이 용도의 `TodayActivity` 컴포넌트는 쓰이지 않고 있었습니다.
- 날짜 없는 업무(FR-015)를 볼 곳이 없어 새 업무에 오늘 날짜를 강제로 넣고 있었습니다.
- 필터는 합집합이었고, 필터의 `오늘`과 월 이동의 `오늘`이 이름은 같고 동작은 달랐습니다.
- 완료 업무가 목록 위에 남았고, 카드마다 `내가 만든 업무`, `등록·실행·마감` 날짜가 반복됐습니다.
- 카드 가운데 50%에 놓으면 하위 업무가 돼, 순서를 바꾸려다 하위로 들어가기 쉬웠습니다.
- 완료 시 처리 결과 입력 유도(FR-016)가 없었습니다.

## 변경

- 오른쪽 패널 기본은 **오늘 보드**입니다: `기한 초과 / 오늘 / 반복 업무 / 날짜 미정`. 업무 하나는 한 섹션에만 나옵니다. 여러 날에 걸친 업무는 오늘이 기간 안이면 `오늘`에 나옵니다.
- 캘린더 날짜를 누르면 그 날짜 목록으로 바뀌고, `← 오늘 보드`로 돌아옵니다. 월 이동의 `오늘` 버튼도 오늘 보드로 돌아옵니다.
- 새 업무는 오늘 날짜가 미리 들어가 있고, 두 날짜를 모두 지우면 날짜 미정으로 저장됩니다.
- 필터는 `전체 / 요청받은 업무 / 반복 업무` 중 **하나만 선택**합니다. 업무 출처는 한 가지뿐이라 두 필터의 교집합은 항상 비므로, 단일 선택이 교집합과 같은 동작입니다. `오늘` 필터는 오늘 보드로 대체했습니다.
- 완료·취소 업무는 목록 아래로 내립니다.
- 카드에는 `내가 만든 업무`를 표시하지 않습니다(요청·반복만 표시). 실행일과 마감일이 같으면 날짜 하나만, 다르면 둘 다 표시합니다. 처리 결과가 있으면 한 줄로 보여 줍니다.
- 드래그: 카드 위·아래 절반은 순서 변경, **오른쪽 1/3에 놓을 때만** 하위 업무가 되며 `하위 업무로` 표시가 뜹니다. 오늘 보드에서는 순서 드래그를 끕니다.
- 처리 결과가 없는 업무를 완료하면 카드에 `처리 결과 남기기` 입력이 잠시 나타납니다. 선택 사항이며 완료를 막지 않습니다(반복 회차는 제외).
- 카드 입력칸에서 스페이스·엔터를 누르면 편집창이 열리던 문제를 막았습니다.
- 쓰이지 않던 `TodayActivity`, `ProjectActivitySummary` 컴포넌트를 삭제했습니다.

## 검증

- `tests/task-board.test.cjs`: 섹션 분류, 완료 업무 정렬, 반복 회차의 오늘/기한 초과 분류, 출처 필터.
- TypeScript, ESLint 통과.

## 제한

- 오늘 보드의 반복 섹션은 오늘 회차만 보여 줍니다. 지난 미완료 회차는 기한 초과에 나옵니다.
