# 레벨테스트·등록 학생 명단, 지표 요약 기간 옵션, 헤더 여러 달 선택

DB: migration `20261006070431_students_and_metric_scope` (모든 새 칸 비워 둘 수 있음 → 기존 데이터·예전 백업 복원 영향 없음).

## 1. 레벨테스트·신규 등록 학생 명단 (로한 요청)

### 결정 (2026-10-06 로한)

- 학생 **실명 저장**(이름·학교·학년). 앱은 로그인한 운영자만 보며, JSON 백업에도 포함된다. 기존 설계(참조번호만)를 이 결정으로 바꾼다.
- 칸 숫자는 **명단 인원으로 자동**. 기존에 손으로 입력한 지난 숫자는 그대로 보존한다.

### 변경

- 학생 기록(`mkt_customers`)에 이름·학교·학년·이전 학원·레벨테스트일 칸 추가(월 수강료·퇴원일은 10-01 추가분 사용).
- 학원 퍼널 지표 역할에 `레벨테스트` 추가. 기존 `레벨테스트` 지표에 역할을 지정했다.
- 대시보드에서 **레벨테스트 칸**을 누르면 그날 학생 명단(이름·학교·학년, 여러 명 추가)이 열린다.
- **신규 등록 칸**을 누르면 그날 등록 학생 명단이 열린다. 레벨테스트 본 학생 목록에서 `등록`으로 옮기거나, `레벨테스트 없이 등록`으로 바로 추가한다. 이전 학원·월 수강료를 함께 기록한다.
- 저장은 RPC `mkt_save_funnel_students` 한 번으로 학생 기록과 그날 칸 숫자(명단 인원)를 함께 저장한다. 명단에서 빼면 다른 명단에 속하지 않는 학생만 휴지통으로 간다(예: 등록한 학생을 레벨테스트 명단에서 빼도 등록 기록은 유지).
- 분석 > **학생·전환** 탭(구 고객·전환): 레벨테스트 인원 → 그중 등록·전환율, 기간 신규 등록, 재원·퇴원, **평균 근속 개월**. 표에 학생(학교·학년), 레벨테스트일, 등록일, 이전 학원, 월 수강료, 다닌 기간, 퇴원일.
- 학생 편집 창에도 같은 칸을 추가했다. 참조번호는 비우면 자동 생성.

## 2. 지표 요약 기간 옵션

- 지표 설정에 **요약 기간**: `기간 안에서만`(기본) / `기간 무관 누적`(처음 기록부터 보고 있는 기간 끝까지).
- 일별 신규 수 지표에 `기간 무관 누적`을 고르면 월간 요약·채널 대표 지표가 처음부터의 총합이 된다. 날짜 칸에는 언제나 그날 입력값만 보인다.
- 로한 결정으로 **당근 단골수·쿠폰 발급수**를 `기간 무관 누적`으로 전환했다. 10월 요약에 9월부터의 총합이 나온다.
- 입력 방식 이름을 정리했다: 일별 신규 수 입력·합산 / 누적 총수 입력·마지막 값 / 현재 상태값 입력·마지막 값 / 계산 지표.
- 시트 행 설명과 채널·지표 관리 목록에 `기간 무관 누적` 표시.

## 3. 헤더 여러 달 선택 (로한 제안)

- 헤더 날짜 컨트롤의 `여러 달`을 누르면 시작 월 ~ 끝 월을 고를 수 있다(연도 넘김 가능). `한 달`로 돌아간다. `‹ ›`는 범위 전체를 한 달씩 옮긴다.
- 대시보드(시트 날짜가 여러 달 이어지고 각 달 1일에 `월/일` 표시, 요약 열은 `기간 요약`), 콘텐츠(`기간 값`·`기간 비용`), 이벤트·분석·리포트(월 단위일 때)가 범위를 쓴다. 업무 캘린더는 월 단위라 끝 월을 보여 준다.
